# Projeto React (Vite)

## Como executar
```bash
npm install
npm run dev
```
Abra o endereço exibido no terminal (normalmente http://localhost:5173).

## Estrutura
- `src/App.jsx` – componente principal com as funcionalidades 2.1, 2.2 e 2.3
- `src/components/Item.jsx` – componente do `<li>` (2.4 e 2.5)
